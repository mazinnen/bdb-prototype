# BDB 対戦テーブル（ビルディバイドブライト 非公式）

ブラウザで動く、ビルディバイドブライトの一人回し・オンライン対戦用の盤面です。
サーバー不要で、GitHub Pages に置くだけで使えます。

## できること
- デッキ登録（テキスト入力、ブラウザに保存）と構築チェック（40〜50枚／バースト12枚ちょうど／ショット12枚まで／同名4枚まで／テリトリー）
- ゲーム準備の自動化：シャッフル → 5枚ドロー → 引き直し（1回） → ライフ10枚（イエロー5・レッド5） → エナジー2枚
- ターン開始時の自動処理：全てスタンド → ドロー（先攻1ターン目はなし）。山札切れはライフから引き、ライフもなければ敗北表示
- ダメージ処理：ライフをイエローの上から1枚ずつめくってドロップへ。バーストは追加1ダメージ、ショットはプレイするか選択
- エンドフェイズ：ダメージ・パワー修正の解除、手札6枚以上なら5枚まで捨てる
- カード操作：クリックでメニュー、ドラッグ＆ドロップで移動、レスト／スタンド、ダメージ・パワー修正、裏向き、テリトリー開放
- 元に戻す（Ctrl+Z）、サイコロ、コイン、ログ、チャット
- オンライン対戦（P2P）：ルームを作って招待リンクを送るだけ

カード効果の処理は自動化していません。効果はプレイヤー同士で処理してください。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作る（例：`bdb-table`）。
2. このフォルダの `index.html` `style.css` `app.js` をリポジトリの直下にアップロード（「Add file → Upload files」でドラッグ＆ドロップ → Commit）。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save。
4. 1〜2分で `https://<ユーザー名>.github.io/bdb-table/` で開けるようになります。

※ 友人内だけで使う場合も、GitHub Pages の公開URLは誰でも開けます。URLを広めなければ実質的に身内専用です。

## オンライン対戦のしくみ
- 通信は [PeerJS](https://peerjs.com/)（WebRTC）で、ブラウザ同士が直接つながります。接続の仲介には PeerJS の無料公開サーバーを使うので、費用はかかりません。
- ホストが「ルームを作る」→ 表示された招待リンク（`?room=XXXXXX`）を相手に送る → 相手が開いて「入る」。
- それぞれ自分の盤面だけを操作します。相手の手札・山札・ライフの中身は相手のブラウザに送られません（公開した手札は見えます）。
- 会社や学校などのネットワークでは、WebRTC が遮断されてつながらないことがあります。その場合はスマホのテザリングなどで試してください。
- ホストがページを閉じるとルームは消えます。

## デッキの書き方
```
T: テリトリー名 / img=表の画像URL img2=開放面の画像URL
4 カード名 / ユニット 赤 C3 P5000 H1 バースト
4 カード名 / コマンド 青 C1 ショット
2 カード名 / エース 赤 青 C4 P7000 H2 img=https://example.com/card.png
```
- 「/」より後ろはすべて省略可能。カード名だけでも動きます。
- 種類：`ユニット` `エース` `コマンド`／色：`赤 青 白 黒 緑 黄 紫`／`C数字`=コスト、`P数字`=パワー、`H数字`=ヒット
- トリガー：`バースト`（`B`）、`ショット`（`S`）。ダメージ処理の自動判定に使います。
- 画像は任意です。`img=` に画像URLを書くと表示されます。

デッキはブラウザ（localStorage）に保存されます。別のPCやブラウザでは見えないので、デッキのテキストはどこかに控えておいてください。
